# DClab — DC tuneR studio

Landing page recreada a partir de la referencia de DC Laboratory: diagnóstico, conexión y sintonización automotriz con una estética oscura de terminal, panel de métricas, descargas, galería y FAQ.

## Abrir localmente

Abre `index.html` directamente o ejecuta un servidor estático:

```bash
python3 -m http.server 8080
```

Visita `http://localhost:8080`.

## Estructura

- `index.html`: navegación, hero, capacidades, descargas, galería y preguntas frecuentes.
- `styles.css`: diseño responsive y sistema visual oscuro con acentos cyan/rojo.
- `assets/`: logo y capturas locales de la interfaz.
